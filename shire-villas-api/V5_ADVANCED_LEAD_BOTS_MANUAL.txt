The bots generate high-quality PUBLIC WEB OPPORTUNITIES daily. They do not

Opportunity until your team verifies it. It cannot be promoted to CRM without
verification and a phone/email, preserving the existing quality controls.

AUTOMATIC DAILY RUN ON RAILWAY
Create a SECOND Railway service from the same GitHub repo:
Root Directory: shire-villas-api
Start Command: python run_daily_bots.py
Cron Schedule example for 08:00 India time:
30 2 * * *
Railway cron uses UTC, so 02:30 UTC = 08:00 IST.

Use the same DATABASE_URL, TAVILY_API_KEY, GROQ_API_KEY and other required
variables/reference variables as the main service. The cron service must exit
after the script finishes; run_daily_bots.py does so.
