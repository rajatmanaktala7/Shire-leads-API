SHIRE VILLAS AI REVENUE OS V4.3 - ROBUST SESSION LOGIN

This package preserves the complete V4.2/V4.1 system.

WHY V4.3
The login no longer sends X-Team-Key from the browser.
Instead:
1. Browser POSTs the key to /auth/login as JSON.
2. Server trims and validates TEAM_API_KEY.
3. Server returns a signed 12-hour session token.
4. Dashboard stores only the session token in sessionStorage.
5. All protected API calls use Authorization: Bearer <token>.

This eliminates browser/proxy/custom-header issues during login.

DEPLOY
Replace the complete shire-villas-api folder with this ZIP.
Keep your existing Railway TEAM_API_KEY and SECRET_KEY.

TEST
1. /health must show 4.3.0
2. Open /app/ in a NEW Incognito window
3. Enter TEAM_API_KEY
4. Button should show "Signing in..."
5. Correct key opens Command Center
6. Wrong key shows "Invalid Team API Key."
7. Login requests time out visibly after 12 seconds rather than hanging

IMPORTANT
Do not put TEAM_API_KEY in GitHub.
Do not change the key again unless the page explicitly reports invalid key.
